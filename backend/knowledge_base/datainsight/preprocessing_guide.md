# DataInsight Preprocessing Guide

DataInsight preprocessing actions include handling missing values, detecting or removing exact duplicate rows, converting supported data types, renaming and deleting columns, and creating columns through restricted arithmetic expressions. Operations update the processed copy and record operation details in processing history.

Review the preview and profile first. Destructive assistant requests are proposed, not automatically executed. Confirm only after checking the target dataset, column, method, and scope. The original upload is retained unchanged.
