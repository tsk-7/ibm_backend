# Data Transformations

Transformations change representation or scale to meet an analysis requirement. Examples include log transforms for positive, strongly right-skewed values, date-part extraction for time analysis, and safe arithmetic derived columns. Select a transformation from the variable meaning and analytical objective, not solely from a visual pattern.

Check input domains, preserve the original when practical, document the transformation, and validate the resulting range and missingness. A transformation is not evidence that the data is normally distributed or causally meaningful.
